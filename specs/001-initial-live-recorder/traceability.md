# 機能と検証の追跡

固定IDの正本は[要求§17と§23](../../docs/requirements.md)。下記は隔離版の代表結果。各IDの全条件、通常運用、外部接続・実機の利用判定は未完了。

| 機能                                            | 関連AC／TC                                        | タスク              | 代表結果                                                                                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 隔離、診断、入力・配信者、HTTP                  | AC-068、AC-083／TC-037・091・110・111             | T004・005・012・015 | 専用ルート、所有・排他、Host／Origin／CSRF、配信者の登録／再登録、読取診断を隔離試験。通常は未実装。                                                                                                    |
| 固定ポートと起動・停止                          | AC-039／TC-070                                    | T005・012・015      | 隔離の既定8083、停止中設定、別ポートへの自動切替なし、現行と次回値、HTTP応答、所有確認付きURL・停止、別領域・古いPIDの拒否を確認。通常の8082とWindows起動は未検証。                                     |
| 両サービスの収集、動画、コメントSRT             | AC-001・021・045・071／TC-010・016・032・042・060 | T006〜010           | ローカルHLSをFFmpegで取得し、各サービスの架空イベント、独立障害、0件・未収集、SRT、同名拒否を確認。ツイキャスの短いページ・途中失敗・不安定な境界の保持を模擬HTTPとSQLiteで検証。実配信未検証。         |
| 音声SRT、統合ASS                                | AC-062・064／TC-085・086                          | T011・T016          | 永続待機列と再投入、FFmpeg実抽出と先頭無音、模擬認識の3種字幕、世代差し替え拒否、改版途中の再照合を確認。モデルなしは保留、音声なしは対象外。実機での認識・GPUは未検証。                                |
| 主要8画面                                       | AC-037・082／TC-109                               | T002・003・012〜014 | 明示選択したAの主要8画面を隔離実装。1024px／1440px・両フォント設定と代表操作を検証。通常運用の機能別設定・再生成等は残件。                                                                              |
| 媒体保全、期限、整合バックアップ、復元          | AC-053・064／TC-047・055・075・086                | T006・011・016      | 隔離期限削除のSRT・ASS先行、動画・音声SRT保持、SQLiteバックアップ、期限削除済みデータと試行履歴の巻き戻り防止、保守中の起動拒否、手動交換後の再照合と差戻しを確認。通常復元・予算照合・一般削除は残件。 |
| Windows／実配信／音声実機                       | FR-001・003・005・010                             | T017                | 未実施。                                                                                                                                                                                                |
