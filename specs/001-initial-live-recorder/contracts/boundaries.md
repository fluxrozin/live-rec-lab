# 実装境界

- 隔離fixture CLIは `live-rec-lab fixture init ROOT`、`live-rec-lab fixture run ROOT`。新規の専用Linux一時領域だけに初期化し、runの入力はコードに含めた架空の配信とコメントに限定する。URL・任意ネットワーク入力を受けない。
- 共通検知はサービスの確定LIVE・確定OFFLINE・UNKNOWNを区別する。録画とコメントがそれぞれ成功・失敗・未収集を記録する。状態変換は事実を上書きしない。
- Webは主要8 URLと下位詳細、同一オリジンのAPI。読取GETと変更操作を分け、変更にはHost・Origin・CSRF等を適用する。媒体パスは必要な表示と照合に使い、ファイル内容を返すルートを持たない。
- 開発モードは専用設定を読み、外部接続を既定拒否する。通常運用・隔離の実接続は要求§15.2.1の許可・共通排他・予算を要求する。
- 動画と字幕の公開は同一ボリュームの一時ファイルから、非上書きまたは管理された版更新で行う。保全できない状態は要確認とし、成功・確定数に含めない。
