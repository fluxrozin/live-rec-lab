## 5案

| 案 | 方向 | 差分の要点 |
| --- | --- | --- |
| A | Heritage Console（既存UI継承型） | 240px サイドバー＋トップバー、KPIカード4枚＋副指標帯、アクティブセッション＋ストレージ。設定は縦カテゴリ＋パネル行＋保存バー |
| B | Precision Workspace（高密度） | 64px アイコンレール、テーブル中心、KPIは1行のインライン統計、行密度重視 |
| C | Operations Monitor（運用監視） | 上部ナビ＋全体ヘルス帯、稼働中セッションを状態タイル化、鮮度バー、右レールに異常・保存先 |
| D | Calm Studio（静穏） | 中央カラム・大きな余白、枠最小、一文サマリー＋行リスト |
| E | Functional Desktop | メニュー・ツールバー・ツリー・マスター/詳細・ステータスバー、設定はタブ付きOK/適用 |
